# Session summary — 2026-05-17 · Marketing & positioning audit

An 8-phase marketing & positioning audit of infraatlas.dev — a strategy to grow
the right audience, build sustainable donation revenue, and protect the
editorial brand from SaaS drift. Donations are the *only* revenue model;
reference class is developer-tool OSS with a tip jar (htmx, caniuse, ripgrep,
Vantage), not a venture SaaS launch. Deliverables under `tasks/marketing-2026-05/`.

## What was done

- **Phase 1 — audit.** Inventoried the marketing surface. Three blockers: the
  GitHub repo is private (so "open-source" is currently false and every GitHub
  link 404s), no donation surface of any kind, no analytics. The voice
  (editorial, dry, exacting) is a real asset with no drift.
- **Phase 2 — research, 4 parallel subagents.** Comparable projects, donation
  economics, discovery channels, SEO/search intent — every external claim
  URL-cited, every estimate explicitly labelled.
- **Phase 3 — positioning.** Primary persona = the senior cloud/platform
  engineer doing architecture work; secondary = the APIM solutions architect.
  One-sentence positioning against Vantage and vendor docs; voice guardrails.
- **Phases 4–8 — strategy.** Growth (three compounding loops, a 5-channel
  shortlist, three dated launch moments); donations (Ko-fi + Open Collective via
  Open Source Europe + GitHub Sponsors, gratitude-moment asks, a public ledger);
  measurement (Plausible EU + Search Console, "returning practitioners" as the
  health metric); an analytics install runbook; a 13-entry anti-list; and a
  weekly-granular 90-day plan.

## Outcome

**Do this week:** make the repo public, stand up a donation surface (Ko-fi +
`.github/FUNDING.yml`), and start the Plausible analytics install. Full strategy
with a 10-minute executive summary: `tasks/marketing-2026-05/report.md`.

## Honest limitations

- Traffic, search rankings and donor numbers are **unmeasurable today** — no
  analytics and no donation channel exist yet. The audit states this plainly;
  the Phase-6.5 analytics install closes the gap.
- Donation-revenue expectations are estimates triangulated from caniuse and
  other public ledgers (labelled `[ESTIMATE]`), not measured forecasts.
- Search-volume figures are deliberately **not** invented — the SEO research
  infers demand from SERP composition and revealed-demand proxies instead.
- The same session also aligned the Region Map's OVH list to the live order
  catalogue and unified masthead typography across instruments — committed
  separately, before this audit.
