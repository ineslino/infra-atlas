About

Instrument 03 of Infra Atlas. The Microsoft cloud's compute catalogue — D-series, E-series, F-series, NC/ND for GPUs, HBv4 for HPC, DCasv5 for confidential, and the ARM Cobalt v6 newcomer. Filter by series, vendor, architecture; see which regions actually have what you need.

Data source

Azure VM series and their regional availability, compiled from Microsoft's public VM size documentation and SKU listings. The status line above carries the current data date. Prices are hourly pay-as-you-go list prices (Linux, USD) from the public Retail Prices API — spot, reserved and savings-plan rates are out of scope.
