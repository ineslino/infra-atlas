About

The Internal Developer Portal layer of Infra Atlas — Backstage, Spotify Portal, Roadie, Port, Cortex, OpsLevel and Atlassian Compass, mapped across the capabilities that actually distinguish them. Click any cell for the note and the source URL. Scope is deliberately narrow: developer portals only.

Sources

Every cell is read off each tool’s official documentation, and the source URL is cited in the cell’s drawer. The space moves fast and the only canonical source is each vendor’s own docs, so this is a curated snapshot — verified 2026-06-06 and reviewed roughly twice a year. If you spot a stale fact, open an issue.
