About

Instrument 02 of Infra Atlas. Every region from AWS, Azure, GCP, Oracle Cloud, and OVHcloud — mapped on one chart so you can see where they cluster, where they don't, and where to put your data.

Data source

Curated from each vendor's public regions page. AWS positions cross-checked with aws ec2 describe-regions. Some location coordinates are approximate (vendors don't publish exact lat/lng for security reasons).
