Privacy.

Infra Atlas is a static reference site. Reading it should not require trusting us with your data — and largely, it does not. Here is the full and honest list.

What is collected

Aggregate, anonymous visit data via Cloudflare Web Analytics — a cookieless, privacy-first product. The dataset is:

  • Pageviews (a count, no identifier)
  • Referrer (the link or search engine that sent the visit)
  • Country (from the connecting IP, not stored against a user)
  • Browser and OS family
  • Core web vitals (load timing, layout shift)

What is NOT collected

  • No cookies. The site sets none, and the analytics provider sets none.
  • No persistent identifiers. No device fingerprint, no visitor ID, no cross-site tracking.
  • No personal data. No accounts, no email list, no forms, no logins.
  • No advertising. No ad networks, no tracking pixels, no retargeting.
  • No data sold. The site has no commercial customers; there is nothing to sell.

Third parties this site loads

Two, in total:

  • Cloudflare — hosts the site, serves the analytics. Cloudflare's privacy policy.
  • Google Fonts — the typography (Instrument Serif, JetBrains Mono, Manrope) loads from fonts.gstatic.com; Google sees the request IP on font load. Google's privacy policy. Self-hosting these fonts is on the roadmap.

Donations

If you support the project via the support page, the donation provider's own privacy terms apply. Infra Atlas does not see your payment details, only the aggregate fact that a donation occurred.

This page is open-source

This privacy notice lives in the same repository as the site. If a claim here is inaccurate, that is a bug — open an issue and it will be corrected.
