Equivalent is rarely 1:1. A security group is not quite a network security group; a global VPC is not a regional one; a stateless subnet ACL has no native match on half these clouds. This matrix maps the closest construct in each cloud — the ◐ marks and the per-cell notes are where the real differences live. Read them before you port a design.

About

Instrument 19 of Infra Atlas. The cross-cloud networking Rosetta stone — every core primitive of the virtual network mapped across AWS, Azure, Google Cloud and OCI, with the semantic caveats spelled out per cell. Click any cell for the note and the source URL.

Sources

Every cell is verified against the provider’s official networking documentation — the AWS VPC, Azure Virtual Network, Google Cloud VPC and OCI Networking docs. Source URLs are cited in each cell’s drawer. Networking constructs are stable but do get renamed and extended, so this is a curated snapshot — verified 2026-05-19 and reviewed roughly twice a year. If you spot a stale fact, open an issue.
